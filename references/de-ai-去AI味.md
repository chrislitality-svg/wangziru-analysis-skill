# 去 AI 味 · 口播稿人话化手册

> 一句话：**AI 味不是用词问题，是"没有人在说话"的问题。** 删掉套话只是表层；真正的人味来自三样东西——**立场、具体、对象感**。
>
> 本文所有"口播基准"都来自「王自如AI」71 个视频（约 50 小时、796,821 字转写）的实测频次。基准是用来对照的，**不是要你凑够这些数**。

---

## 一、先看数据：50 小时口播里，这些词几乎不存在

| AI 稿高频写法 | 71 篇口播实测 | 他实际怎么说 |
|---|---|---|
| 值得注意的是 / 由此可见 / 换言之 | **0 次** | 直接说结论；要强调就说「我一定要强调」 |
| 至关重要 / 有效地 | **0 次** | 「非常重要 / 最核心」，或者直接给后果 |
| 在当今……时代 / 总的来说 / 希望对你有所帮助 | **0 次** | 开场用钩子，结尾用收口句 |
| 综上所述 | 1 次 | 「一句话总结」 |
| 此外 / 与此同时 | 3 次 / 1 次 | 「再一个 / 那么」（「那么」15.7 次/万字） |
| 首先……**其次**……最后 | 首先 159 次，**其次只有 7 次** | 「第一 / 第二 / 第三」（847 / 620 / 206 次） |
| 一方面……**另一方面** | 一方面 37 次，**另一方面只有 2 次** | 只讲有用的那一面，不凑对称 |
| 不是 A，而是 B | **0.6 次/万字**（一条 8 分钟视频约 0.1 次） | 全片只用一次，用在纠偏主句上 |
| 不仅……而且/更 | 0.3 次/万字 | 「而且」单用（5.6 次/万字） |

反过来，口播里**高频出现**、AI 稿里几乎没有的：

| 人味信号 | 71 篇口播实测（次/万字） |
|---|---|
| 你 | 153.8 |
| 我们 | 49.1 |
| 其实 | 31.6 |
| 大家 | 28.8 |
| 我觉得 | 22.9 |
| 对吧 | 20.8 |
| 那么 | 15.7 |
| 吗 + 呢（设问） | 41.9 |
| 数字（含「三个」「十五年」这类中文数量） | 181 |

**读法**：AI 稿是"上帝视角的说明书"——没有"你"、没有"我觉得"、没有数字；口播是"一个人对着你讲他的判断"。

## 二、十类 AI 味特征（识别 → 为什么像 AI → 改法）

### 1. 书面连接套话
- **识别**：首先/其次/此外/与此同时/值得注意的是/由此可见/综上所述/总的来说
- **为什么像 AI**：这些词在书面论文里负责"显得有条理"，嘴上没人这么说。
- **改法**：编号用「第一/第二」；转折用「但是」并在前面停半拍；收束用「所以说 / 一句话总结」。能删就删——口播的条理靠**停顿和编号**，不靠连接词。

### 2. 对称凑数
- **识别**：一方面…另一方面、三个四字词排比、「不仅…更…」、每段都是"观点+解释+总结"三件套
- **为什么像 AI**：模型偏爱结构对称，真实判断往往是不对称的（一面很重要，另一面顺带一提）。
- **改法**：只保留真正有话说的那一面；排比全片最多一组，且末句放慢轻收。

### 3. 「不是 A，而是 B」滥用
- **识别**：一篇里出现 2 次以上；或者 A 没有先"让半步"就被推翻
- **为什么像 AI**：这是 AI 最爱的"深刻感"句式。它在王自如手里是**核武器**——一期只用一次，用在全片的纠偏主句上。
- **改法**：全稿保留 1 次（纠偏主句）；其余改成陈述句，或拆成「A 有道理。/ 但是它很片面。」两拍。

### 4. 宏大空词
- **识别**：赋能/助力/抓手/深度融合/降本增效/数字化转型/时代浪潮/前所未有/系统性工程/顶层设计/长期主义
- **为什么像 AI**：这些词什么都没说，却显得说了很多。
- **改法**：换成**动作或数字**。「深度融合」→「让它进到审批流程里」；「降本增效」→「一个人干三个人的活」。商业黑话全片每词 ≤2 次，首次出现紧跟一句翻译。

### 5. 修饰堆叠
- **识别**：至关重要/不可或缺/显著/有效地/切实/极大地
- **为什么像 AI**：形容词是在替读者下判断，缺证据时尤其多。
- **改法**：删掉形容词，用后果说话。「人才培养至关重要」→「没人会用，买再贵的系统也是摆设」。

### 6. 上帝视角，没有人称
- **识别**：通篇"企业应当……管理层需要……"，没有「你/我/我们」
- **为什么像 AI**：没有说话的人，也没有听话的人。
- **改法**：主语换成观众——「企业应当明确战略」→「如果你是老板，你第一件事该问什么？」；判断前加「我觉得 / 在我看来」，让观点有主人。

### 7. 无立场的平衡收尾
- **识别**：各有利弊 / 因人而异 / 需要综合考虑 / 总的来说……都很重要
- **为什么像 AI**：模型被训练成不得罪人。没有立场就没有纠偏，没有纠偏就不是这套系统。
- **改法**：给判断，再给"可被打脸的条件"——「我的判断是 X；如果 Y 发生了，你们来打脸」。

### 8. 书面标点与长句
- **识别**：破折号、分号、冒号列表；一口气念不完的分句（逗号之间 >20 字）；定语往名词前面堆（的的的）；分句之间没有逻辑词，"……，……，……，……"一逗到底
- **为什么像 AI**：嘴巴念不出标点，也一口气念不完 25 字。注意问题不在句子长：他论证时一句话中位约 30 字、要分三四口气说完，但每口气只有 10 字左右，口气之间靠因为 / 所以 / 它接起来（`syntax-长句逻辑.md`）。AI 的长句是定语长、分句长、关节处没有词。
- **改法**：破折号换成停顿（`//`）；分号改成逗号加连接词；长定语拆出来，用「它 / 这」回指；分句之间补上因为、所以、但是、如果…那。**别把长句剁成一串短句**，那样逻辑关系就要观众自己猜了。

### 9. AI 腔开头结尾
- **识别**：在当今……的时代 / 随着……的快速发展 / 让我们一起来看看 / 希望本文对你有所帮助 / 欢迎在评论区留言
- **为什么像 AI**：模板化的起承转合。
- **改法**：开场用 `blueprint-template.md` 的钩子库（数字冲突 / 反常识结论 / 审题），12 秒 ≤40 字；结尾用 ≤12 字收口句 + 一个真实破功点。

### 10. 没有具体
- **识别**：没有数字、没有案例、没有场景；全是"很多企业""某些情况"
- **为什么像 AI**：模型不知道你的具体情况，就只能说正确的废话。
- **改法**：每个论点配一个**数字**或一个**场景**（「一个顶尖实习生第一天来上班，没账号、没资料」）。手里没有真实数据就标 `[用户补充]` / `[待核实]`——**宁可留空，不许编**。

## 三、去 AI 味的顺序（别反过来）

1. **跑检测**：有 Python 就跑 `python tools/ai_flavor_check.py 稿子.txt`，拿到 AI 味指数和命中清单；没有就按第二节十类逐条人工扫。
2. **先修结构**：有没有立场（第 7 类）？有没有具体（第 10 类）？这两个不修，删再多套话也还是 AI 稿——这一步通常要回到《拆解蓝图》重拆。
3. **再修句式**：「不是A而是B」砍到 1 次、拆一口气念不完的分句、补逻辑词、去对称（第 2、3、8 类）。
4. **最后换词**：套话、空词、修饰词（第 1、4、5、9 类）。
5. **换人称、加设问**：把"企业应当"改成"你"，把陈述改成一问一答（第 6 类）。
6. **朗读测试**：念出来。卡嘴的地方、需要换气才念得完的地方、你自己都不会这么说的地方，就是还没改完的地方。
7. **复检**：再跑一次检测，交付时给出前后分数。

## 四、别矫枉过正

- **不要满屏「对吧」「其实」**：口头禅是腔调，不是人味。「对吧」全片 ≤15 次且独立成拍。往稿子里硬塞口头禅，就是本 skill 反对的"学腔调不学结构"。
- **不要把所有书面词都删光**：「首先」「本质」他也常说；问题是**套路化的组合**（首先/其次/最后 + 值得注意的是 + 总的来说）。
- **指数只是起点**：检测器数的是表层信号。一篇 0 分的稿子，如果没有立场、没有具体，依然是空的；一篇有立场、有具体、偶尔用了个「此外」的稿子，比它强得多。

## 五、检测器怎么算分（透明公式）

`tools/ai_flavor_check.py`，零依赖，Python 3.8+。AI 味指数 0–100（越高越像 AI）：

| 扣分项 | 规则 | 封顶 |
|---|---|---|
| 套话 / 空词 / 修饰 / AI 腔 | 每千字命中数 × 8 | 35 |
| 对称凑数 | 每千字每处 × 6 | 12 |
| 「不是A而是B」 | 每 2000 字放行 1 次，超出每次 × 6 | 18 |
| 破折号 / 分号 | 每千字每个 × 2 | 8 |
| 一口气念不完：逗号之间的分句 >25 字 | 每千字每处 × 3 | 9 |
| 人称密度 <12 / 千字 | +8 | — |
| 设问密度 <2 / 千字 | +5 | — |
| 数字密度 <2 / 千字 | +5 | — |
| 逻辑词（因为 / 所以 / 但 / 如果 / 那么 / 它…）<12 / 千字 | +5 | — |

不足 1000 字按 1000 字算。分档：**<20 人话 · 20–40 轻微 · 40–60 明显 · ≥60 重度**。

**校准**：用 71 篇原片转写自测，中位 10 分，92% 低于 20 分，最高 25 分；本仓库 `examples/02` 里的典型 AI 稿 73 分，按本 skill 改写后 0 分。

**v1.3 改了什么**：原来的「长句 >30 字」扣分项删掉了。他论证时一句话中位约 30 字，按语法断句有 45% 的句子超过 30 字；原先的「口播句长中位 18 字」量的是转写的气口。现在只对一口气念不完的分句（>25 字，他只有 3%）扣分，另外对逻辑词太少（<12 次/千字，他的长视频最低一期 14.5）扣 5 分。
