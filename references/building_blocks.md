# 题型积木块、比喻与金句库

这些是可选项。一篇里用不上的模块直接删。不要为了「像他」把审题、让半步、排除两连、比喻双回收全部走一遍。取舍以 `logic-checks.md` 为准。

---

## 1. 题型怎么裁

不跑完整十段。没给时长时按 2 到 3 分钟、大约 600 到 800 字，只留这题真正要回答的几段。

### 1.1 认知正片（默认形态：商业机制 / 硬件产品 / 品类分析）
- **骨架精简版**：
  1. **开场审题**：3秒破题，宣告考题感。
  2. **私有命题**：抢走定义权，砸下 4-8 字概念（「在我看来，/ 其实就叫做【四字概念】」）。
  3. **纠偏换尺**：立靶 ➔ 让半步 ➔ 换尺（不是A而是B） ➔ 维度碾压封口。
  4. **主比喻登场**：从生活动作或空间资产中提取比喻本体。
  5. **排除法处刑**：借观众之嘴排除 2 个最易想到的替代方案，给出具体死因与重锤词。
  6. **框架编号（2-3条）**：带零头的结构（「两个半创新」），逐条推进。
  7. **比喻回收一 & 二**：在排除之后和收尾之前各拉回一次比喻。
  8. **断言收口 & 破功**：≤12字短句降调定音，紧接自嘲。

### 1.2 个人叙事（人生抉择 / 个人转型 / 创业复盘）
- **骨架精简版**：
  1. **质疑排比摊牌**：将外界最尖锐的 2-3 个「为什么」直接列上桌 ➔ 「既然你点了进来，不妨换个视角」。
  2. **第二人称叙事（你=我）**：灾难开局 ➔ 准确数字造真（「1500个申请者里那个唯一被录取的幸运儿」）。
  3. **实物隐喻贯穿**：寻找一个高质感实物锚点（如「橱窗里的球鞋」）。
  4. **动作瀑布清单**：讲述抉择代价时一句一个动词，不加形容词（「卖了车子，/ 卖了房子，/ 给员工发了遣散费」）。
  5. **降姿态哲学收束**：主动承认局限（「其实所有的成长都来自趋势的托举」）。
  6. **切回第一人称“我”**：承认做不到完美 ➔ 「但至少做到不抱怨」 ➔ 评价权交给网友 ➔ 笑场彩蛋。

### 1.3 短评 / 观点反驳（热点事件 / 社会议题 / 争议纠偏）
- **骨架精简版**：
  1. **直捣黄龙立靶**：不铺垫废话，直接将公众热议的表象拎出来。
  2. **剥离情绪翻译机制**：把道德判断或个人恩怨降维翻译为「商业与生存机制」（如彩礼=抚养成本补偿；西贝=内部口碑反噬爆发）。
  3. **推翻单一归因**：打碎外界给出的简单凶手（「没有一家企业是被黑粉骂死的」）。
  4. **揭示结构死法**：给出现实的必然机制（「只是推迟发生，两种死法而已」）。
  5. **自嘲回扣闭环**：借自身经历举重若轻地调侃（「就像老罗的锤子死了也不是我的问题，循环了没有兄弟们」）。

### 1.4 教程 / 实操型（项目复盘 / 方法论沉淀）
- **骨架精简版**：
  1. **成果数字立威**：用真实的数字与时间周期开场。
  2. **需求本质解构**：剔除伪需求，聚焦不可妥协的核心约束。
  3. **竞品盲区排除**：指出同行方案的致命死穴。
  4. **决策树框架**：2-3个模块，明确输入输出与机制。
  5. **哲学收尾**：从工具升维到认知态度。

## 2. 主比喻构建与双回收范式

一期最多一个主比喻。第二次出现时必须多说出一层，不能只把名字再说一遍。说不出新的一层，就不要第二次。回收次数不够，好过两次都是空的。

### 2.1 比喻仓库与适用主题
- **生活动作类（最优先）**：
  - *收纳行李箱*：适用于空间/容量/硬件堆叠/多任务调度约束。
  - *掰馍吃泡馍*：适用于循序渐进、不可跨越的工艺或训练周期。
  - *140字写文言文*：适用于极端工程限制下的极限取舍。
  - *小狗握手（火腿肠刺激）*：适用于用户行为激励机制、算法驱动与反射。
- **空间与消费类**：
  - *毛坯房 vs 精装房*：适用于开源框架 vs 商业闭环产品、底层系统 vs 原生体验。
  - *商场与门票*：适用于生态平台垄断、抽税逻辑与流量分配。
  - *橱窗里的球鞋*：适用于阶层跃升、个人追求与现实代价。
- **机械与动力类**：
  - *轿车与卡车*：适用于轻量化通用工具 vs 重型工业级应用。
  - *F1分站赛冠军 vs 积分总冠军*：适用于单项参数跑分 vs 综合用户体验。

### 2.2 比喻回收的两个固定点位
- **点位 1（排除处刑或框架展开中）**：
  - 在排除竞品或阐述第一条框架时回收。
  - *范例*：「这就好比你把毛坯房刷了一层腻子粉，/ 你就敢说自己是拎包入住的精装房，/ 根本不是一回事。」
- **点位 2（断言收口或升华收尾中）**：
  - 在给出终局判断前回收，形成首尾呼应的思维闭环。
  - *范例*：「所以说回到最后，/ 大家争来争去，/ 无非是在这间精装房里/ 到底留几个插座的问题。」

## 3. 收口断言与自嘲破功金句库

### 3.1 经典收口断言（≤12字，绝对化/否定/数字优先，降调）
- 「【没有人】干得过苹果。」
- 「【摇摆人群】决定商业走向。」
- 「结构化数据 is everything。」
- 「估值没有意义，/ 做订单才有价值。」
- 「轿车普及得再多，/ 卡车也不会消失。」
- 「真诚就是【最优】战略。」
- 「买门票的时代，/ 彻底过去了。」

### 3.2 自嘲破功彩蛋（升华之后把气放掉，防止油腻）
- 「循环了没有兄弟们？」
- 「不对，比错手势了是不是？哈哈哈哈。」
- 「这个可能要靠网友自己重判了。」
- 「就好像当年那个事儿，也不是某一个人的问题，一个道理。」
- 「今天的视频就先到这，我们下次再见。拜拜。」
