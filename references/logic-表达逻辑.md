# 表达逻辑 · 先讲什么，为什么，怎么递进，怎么举例，怎么收回开头

> 这套方法真正值钱的不是句式，是**论证的顺序**。本文从他四条代表作的完整转写里拆出逻辑链，归纳成能直接套用的规则。拆解、成稿、体检、去 AI 味，**都先过这一层**；词频、句长、AI 味指数只是后面的辅助检查。
>
> 这是篇章层。句子层（一句话里、句与句之间怎么把推理说出来）见 `syntax-长句逻辑.md`。
>
> 文中「」内是概括转述，不是原话。
>
> 样本（有机表现最好的四类）：《对轻薄手机认知》（纠偏评测）·《我又要创业了！》（个人叙事）·《过去的 48 天 我经历了什么》（复盘）·《解构「龙虾」》（技术解读）。

---

## 一、四条公理（四条视频里都成立）

### 1. 开头先欠观众一笔账

每条视频的开头都立下一笔「后面必须还的债」，而且是具体的：

| 视频 | 开头欠下的账 | 在哪还 |
|---|---|---|
| 对轻薄手机认知 | 一个总命题（这是一场极致的权衡），加一个纠偏承诺（换掉厚度这把尺） | 换尺在 4–9% 处兑现，命题在结尾升级为行业判断 |
| 我又要创业了 | 结论先报（又创业了），再把外界四个追问原样摆上桌 | 片尾（14:02）本人出场，点名结账 |
| 过去的 48 天 | 一个场景：团队开会，日程谁也说不清，市面工具全要填表 | 结尾重演一场开会，一张图建好 9 个日程 |
| 解构龙虾 | 一个反差：技术不新，为什么这么火 | 四层原因逐层回答，结尾把「解构」升成方法 |

**规则**：开头那句话写完，问自己「观众现在欠着什么没听到」。答不上来，开头就是空的。

### 2. 先立尺子，再下判断

四条视频无一例外：**任何「好 / 坏 / 对 / 错」出现之前，先把评判标准立起来**。

- 对轻薄：先论证「该看绝对容量，不该看厚度」，四款手机才有统一的量法；否则「荣耀更厚却更好」会被观众当场否定。
- 创业：先讲清「什么样的机会值得押上一切」（进核心企业、任核心岗位、亲身验证），机会出现时只需逐项打勾，选择就成了对标的结果，不像冲动。
- 48 天：演示完先把「它难在哪」拆成三条能力，下一段拿同一份清单逐个检验现成方案，「为什么要自己做」不用另外论证。
- 龙虾：产品和范式分开打分，用「听懂了多少」作尺子给观众分档。

**规则**：尺子要**可计算、可演示、可验证**；用之前先交代它的误差（对轻薄主动讲了容量估算的误差来源）。尺子所在的那一段，通常就是全片的承重段。

### 3. 每一段回答上一段留下的问题

段与段之间不是并列，是**问答咬合**：上一段结尾留下一个观众必然会问的问题，下一段回答它。

| 视频 | 问答链 |
|---|---|
| 解构龙虾 | 为什么火？→ 门槛降了 → 那为什么不神化？→ 智能看模型 → 那它新在哪？→ 本地化 + 记忆 → 那为什么手机上被封、PC 上被捧？→ 权限哲学 → 那为什么两种哲学不同？→ 历史和商业 |
| 过去的 48 天 | 做出了什么？→ 演示 → 真的吗？→ 真实 API 声明 → 现成的不行吗？→ 四个替代方案逐个排除 → 那你怎么做？→ 架构 → 值不值？→ 代价与收获 |
| 我又要创业了 | 为什么离开？→ 成长靠大势 → 大势变了吗？→ 朋友关公司 → 下半场在哪？→ 产业互联网 → 为什么不直接做？→ 先验证 → 验证了吗？→ 验证了，但被打断 → 下一步？→ AI 服务产业 |

**过桥的三种做法**：
- **借观众之口问**：「很多朋友会问」，然后回答。
- **反差自问**：前面越肯定，越要问一句「那它有没有代价」。
- **推演的终点变成新问题**：对轻薄的「砍摄像头」推演，推到底就引出了下一个工程难题。

**规则**：每段写完，用一句话说出「它回答了上一段的什么」。说不出，这段就是插进来的。

### 4. 有一段删掉就会塌

每条视频都有一段**承重段**，后面所有判断都从它来：

| 视频 | 承重段 | 删掉之后 |
|---|---|---|
| 对轻薄手机认知 | 纠偏换尺（不看厚度看容量） | 退化成普通的四机横评，「更厚却更好」不成立 |
| 我又要创业了 | 产业互联网的判断 + 亲身验证的标准 | 格力那几年成了说不清的转行，退化成换工作的流水账 |
| 过去的 48 天 | 实机演示 + 真实性声明 | 所有架构讨论成了空中楼阁 |
| 解构龙虾 | PC 管理员权限 vs 手机沙箱 | 「本地 Agent 会成为 PC 基建」成了光秃秃的断言 |

**规则**：拆解或体检时，先找承重段。找不到，说明全片没有一个真正的论点，只是在罗列。

## 二、四种推进骨架（按题材选）

| 骨架 | 代表作 | 顺序 | 适合 |
|---|---|---|---|
| **先定尺，再测量** | 对轻薄手机认知 | 定性 → 换尺 → 讲清尺子怎么量 → 选一个基准深拆 → 其余按「对基准的回应」依次测 → 上升到行业格局 | 纠偏型评测、多对象对比 |
| **结论先行的倒叙决策链** | 我又要创业了 | 报终点 + 摆质疑 → 回到起点 → 前提 → 信号 → 问题 → 立标准 → 机会出现、逐项打勾 → 兑现代价 → 打断 → 新结论 → 本人出场结账 | 个人叙事、回应质疑 |
| **成品先行，按决策组织** | 过去的 48 天 | 痛点场景 → 成品演示 → 自证真实 → 立难度标准 → 用标准排除替代方案 → 按层级讲关键决策（只在认知变化最大处用时间线）→ 代价 → 收获 → 重演开头场景 | 复盘、作品展示、教程 |
| **反差立题，层层下挖** | 解构龙虾 | 祛魅 → 抛反差 → 逐层追问原因 → 用同一条根因预测未来 → 立刻给预测打折 → 推到「和你有什么关系」 → 按受众分档给建议 → 升成方法 | 热点解读、技术认知 |

**共同点**：判断都放在证据之后，预测都放在原因之后，升华都放在最后。放在前面，就成了没有根据的断言。

## 三、案例怎么放

### 位置规则

- **绝大多数案例放在论点之后**，作证据，或者把抽象概念变得看得见。
- **放在论点之前的案例只有几类**：痛点场景、对照组、成品演示、错误做法、权威引言。它们的任务是**把问题立起来**，不是证明论点。

### 类型与作用

| 类型 | 作用 | 例 |
|---|---|---|
| 对照组 | 排除表面解释，让真正的原因浮出来 | 龙虾：先证明豆包手机和龙虾底层逻辑相同，差别只能出在平台上 |
| 类比 | 让外行听懂，还能**生出新论点** | 精装房 vs 毛坯房，推出「易上手、难精通」，后面又收回成「拎包入住」 |
| 亲历数字 | 让内行信服 | iOS 原生日历要两个月，Web 一天就调好 |
| 极端假设 | 反证或推出结论 | 容量无限大就谈不上取舍；七十岁还坐在镜头前 |
| 自己的经历 | 用在「连懂行的人都会卡住」这种关键处，并主动交代局限 | 自己配完龙虾也干不了活；代码里还有耦合，正在重构 |
| 请观众亲测 | 把验证权交出去，化解替厂商站台的嫌疑 | 去线下店把两台手机前后比一比 |

### 三个高级用法

1. **一个案例反复用，每次功能不同。** 豆包手机在龙虾里出现 4 次：行业背景 → 核心反差 → 「起大早赶晚集」的类比 → 对照「PC 会更快」。
2. **框架里举的例子，变成后文的测量线。** 对轻薄在框架段举了「一颗摄像头顶三颗」「小空间塞大电池」两个难题，后面四款手机都按这两条线重测，多对象比较才不散。
3. **类比 + 亲历数字成对出现。** 48 天的每个技术决策都配一个日常类比（让外行懂）和一个前后对比的数字（让内行信）。

## 四、首尾怎么呼应

| 方式 | 做法 | 例 |
|---|---|---|
| **场景重演**（最强） | 开头的具体场景在结尾再演一遍，结果已经不同 | 48 天：开头开会没人说得清，结尾开会一张图建好 9 个日程 |
| **账单结清** | 开头摆出的问题，结尾由本人点名回收 | 创业：本人出场，明说其余追问的答案都在前面的讲述里 |
| **方法升格** | 开头对一个对象做的事，结尾抽象成方法 | 龙虾：开头给技术祛魅，结尾给品牌祛魅：看范式，不看品牌 |
| **比喻三次回收** | 一个物件在「够不着 / 拿到了 / 已拥有」三个节点出现，兼作阶段标记 | 创业：橱窗里的球鞋 |
| **伏笔回收** | 前面不起眼的细节，后面变成关键理由 | 创业：下班学做视频 → 做回讲故事的手艺人 |

**不是每条都闭环**：对轻薄的尺子（容量）在结尾没有再出现，母题延续了，但没有回到「别再只看厚度」。所以写稿时把呼应当成**必须检查的一项**，不要默认会自然发生。

## 五、段内的小结构

- **四拍**：先给结论或原则 → 一个日常类比 → 换来的收益（尽量给数字或前后对比）→ 主动交代代价。最后一拍是在给可信度买保险（48 天第 6–8 段）。
- **讲完优点就补代价**：荣耀加了电池，就讲背盖换成玻纤、质感下降（对轻薄）。
- **先压后抬**：先如实压低对象的硬实力，再肯定它代表的方向（龙虾：看空 OpenClaw，看多本地 Agent）。
- **在质疑必然出现的位置自问自答**：展示成品后回应「现成的不行吗」，展示复杂设计后回应「是不是做过头了」；回应时把问题往上提一层，变成「你的目标是什么」。

## 六、逻辑链表（拆解、成稿、体检都用这张表）

| 段 | 讲什么（一句话） | 为什么放在这里（回答了上一段的什么） | 理由与证据 | 怎么推到下一段（留下什么问题） | 案例（是什么 / 论点前还是后 / 作用） | 呼应谁 |
|---|---|---|---|---|---|---|

**逻辑体检五问**（体检模式先问这五个，再看句子）：

1. 开头欠了观众什么账？结尾还了吗？
2. 第一个判断出现之前，尺子立了吗？尺子能验证吗？
3. 每一段能不能用一句话说出「它回答了上一段的什么」？有没有插进来的段？
4. 每个案例是在立问题，还是在证明论点？证明用的案例是不是紧跟在论点后面？
5. 承重段是哪一段？删掉它，后面会不会塌？如果删掉哪段都不塌，说明全片没有论点。
