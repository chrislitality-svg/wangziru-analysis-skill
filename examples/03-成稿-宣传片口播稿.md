# 示例 03 · 模式 B 成稿：宣传片《我们蒸馏了王自如》口播稿

这条介绍本 skill 的竖屏宣传片（约 2 分钟），文案就是用 skill 自己拆、自己写的——片尾那句"如果你听着有点像他，那就对了"说的就是这件事。

> 注：视频发布时 skill 只有三种用法；「去 AI 味」（模式 D）是之后加的。这篇按 v1.2 以前的「单句 ≤18 字」写，句子偏短；按 v1.3 的长句逻辑怎么改，见 [示例 04](04-成稿-给方法做体检.md) 第三节。

**AI 味检测**：0 / 100（人话）· 句长中位 17 字、P90 22 字 · 逻辑词 27.0 次/千字 · 「不是A，而是B」全片 **1 次**，用在纠偏主句上（第 9 句）——正是规则要求的用法。

---

## 一、结构对照：28 句怎么落在骨架上

|---|---|---|---|

## 二、纯净稿（直接念）

```
我们把王自如七十一个视频，蒸馏成了一个skill。
为什么是他？
因为我太欣赏他的表达逻辑了。
再乱的话题，到他嘴里都会变得有秩序。
他给的案例和方案，你听完一句话就能复述。
所以我就想，能不能用他的方式，来处理我自己的选题？
很多人学一个人，学的是金句和口头禅。
这有道理，但是非常片面。
真正值钱的不是腔调，而是处理问题的顺序。
先审题、下定义，再纠正偏差、换一把尺子。
然后排除掉别的方案，给出框架，最后一句话收口。
那直接让AI模仿他说话，行不行？
你会发现，它只学得到口头禅，学不到结构。
所以我们做了一件笨功夫。
五十个小时音频，近八十万字转写，一篇一篇拆。
连对吧这两个字出现了一千六百六十次，都数了出来。
最后蒸馏成了一个skill，三种用法。
第一，拆解。给它一个选题，先出一张拆解蓝图。
第二，成稿。蓝图过了质量门，再写成能直接念的口播稿。
第三，体检。把旧稿丢进去，先告诉你最致命的问题。
比如我丢给它一个选题，AI如何在企业落地。
它给出的定义只有六个字，给AI办入职。
要核实的数据全部标出来，绝不替你瞎编。
声明一下，我们没用他的声音和肖像，这是一份表达方法研究。
一句话总结，学结构，不学腔调。
想要这个skill的，关注我，评论区扣蒸馏，我发给你。
对了，这条视频的文案，也是用它拆出来的。
所以如果你听着有点像他，那就对了。
```
