# 示例 04 · 模式 B 成稿：《我给自己的 skill 做了次体检》

用来说明这次 skill 为什么更新的一条口播（约 2 分钟）。它同时是一次"自证"：稿子完全按 [数据复盘](../references/data-量化复盘.md) 改回来的新规则写。

**AI 味检测**：8 / 100（人话）· 句长中位 16 字、P90 25 字 · 确定词 0 次 · 「不是 A 而是 B」全片 1 次，位于 20% 处 · 654 字，按 300 字/分约 2 分 10 秒。唯一扣分项是统计术语「显著」，保留。

---

## 一、Step 0 与简版蓝图

| 项 | 内容 |
|---|---|
| 形态 | 认知正片（短版） / 2 分钟 |
| 目标 | 涨粉、点赞、收藏；体现对 AI 与数据方法的专业度 |
| 价值类型 | **投币型为主**（讲一次真实的自我检验和改错），**收藏型为辅**（给一把可带走的尺子 + 开源工具） |
| 定义（≤8 字） | 给方法做体检 |
| 大众认知靶 A | 看博主看播放量（让半步：播放最直观） |
| 换尺 B | 看投币：投币要花硬币，最难被活动刷出来（可验证：9 个视频占 24% 播放） |
| 框架（编号路标） | 体检三条：手册四处对不上 / 反常识标题不加分 / 场景开场好过数字开场 |
| 主比喻 | 体检（回收 2 次：收口句、评论区口令） |
| 收口（≤12 字） | 方法也要过体检（7 字） |
| 免责 / 专业感 | 140 组检验校正后没有一项显著，所以只当方向，不当规律 |
| 破功 | 这条稿子本身就是按新规则写的 |

**新规则在稿子里的落点**：开场是一个具体时刻，没有先甩数字；「不是 A 而是 B」只用一次且在前四分之一；编号「第一 / 第二 / 第三」做路标；确定词 0 次；标题写经历和结论，不写反常识。

## 二、标题候选

| 标题 | 依据 |
|---|---|
| **我给自己的 skill 做了次体检** | 经历 + 动作，不反常识（首选） |
| 拿 71 期数据，体检我的写稿方法 | 经历型数字 + 结论 |
| 做完 skill 之后，我用数据查了一遍它 | 经历 + 过程 |

简介：把王自如 71 期视频的转写和 B 站数据放在一起重算，检验我们自己的写稿 skill：四处说法和数据对不上，全部改掉，顺手开源了一个看真实表现的小工具。

标签：#AI工具 #数据分析 #Claude #AISkill #口播文案 #内容创作 #B站运营 #王自如

## 三、纯净稿（直接念）

```
上个月，我们把王自如七十一个视频，蒸馏成了一个写稿的skill。
用了一段时间，我心里一直压着一个问题。
这套方法，拿他自己的数据验证过吗？
答案是，没有。
所以这一期，我做了一件事，我管它叫：给方法做体检。
用他自己的数据，反过来检验从他身上学来的方法。
很多人看一个博主，第一眼看播放量。
这有道理，播放最直观。但它非常片面。
判断一个视频有没有被认可，要看的不是播放，而是投币。投币要花硬币，最难被活动刷出来。
七十一个视频里，有九个播放很高，投币却大多只有同类视频的一到三成。
这九个只占百分之十三，却拿走了百分之二十四的播放。
其中八个，和品牌活动有关。
照着它们学，会怎么样？学偏了。
用这把尺子重新量，体检结果有三条。
第一，我们自己的手册，有四处和数据对不上。
比如我们写过，收口要慢到一分钟一百多字。可他的成片，从头到尾都是一分钟三百字左右，几乎是匀速的。快和慢，是剪出来的。
第二，反常识的标题，没有换来更多认可。不酷了、被高估这一类标题，分享、收藏、投币都更低。
第三，开场先讲一个场景，比先甩一串数字好。开场数字越密的视频，投币反而越少。
还有一句话，我得说清楚。这次我们一共做了一百四十组相关检验。
做完多重比较校正，没有一项是显著的。
所以上面这些，我把它当方向，不当规律。
在我看来，敢把这句话说出来，比任何一个漂亮结论都重要。
这就是我们更新skill的原因。
四处写错的，全部改掉。开场改成场景优先，再加一道确定词的门。
还开源了一个小工具。
输入B站视频的BV号，就能标出哪些播放被放大了。
一句话总结，方法也要过体检。
这把看投币的尺子，你下次看任何博主都用得上，先收藏。
觉得这次体检做得值，点个赞。
想要工具和新版skill，关注我，评论区扣体检，我发给你。
对了，这条稿子就是按新规则写的。开场是一个场景，那个最容易被AI用滥的句式，全篇只用了一次。
```

## 五、事实核对

| 稿中说法 | 依据 |
|---|---|
| 九个视频播放高、投币大多只有同类一到三成 | 9 个带指纹视频中 7 个的投币率为同形态中位的 9%–33% |
| 占 13% 的视频拿走 24% 的播放 | 9 / 71；指纹视频播放占全部播放 24.1% |
| 其中八个和品牌活动有关 | 荣耀 ×3、雷鸟 ×3、荣威、路特斯；人形机器人那期是 WAIC 逛展播客，未见合作 |
| 手册四处和数据对不上 | 框架编号位置、语速曲线、直播快慢、主比喻位置 |
| 成片一分钟三百字左右，几乎匀速 | 15 条长视频十等分后每段 303–321 字/分 |
| 反常识标题分享、收藏、投币都更低 | 同形态百分位差 −0.36 / −0.29 / −0.25，p = 0.005 / 0.016 / 0.050 |
| 开场数字越密，投币越少 | 有机长视频 ρ = −0.62，n = 17（线索级） |
| 140 组检验，校正后没有一项显著 | Benjamini–Hochberg 校正后最小 q = 0.73 |
