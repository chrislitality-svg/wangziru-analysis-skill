# 王自如式表达拆解 · wangziru-analysis

> 学结构，不学腔调。

一个给 AI 编程助手（Claude Code / Codex / Cursor 等）用的 **Agent Skill**：用王自如的表达系统，把一个"大家都在聊、没人讲清楚"的选题，拆成**观众听完能复述的思考框架**，再按需写成口播稿，或者给你的旧稿做体检。

我们把「王自如AI」B 站 **71 个视频**（57 个正式视频 + 14 场直播回放，约 **50 小时**口播、近 **80 万字**转写）一篇一篇拆完，连「对吧」这两个字出现了 **1660 次**都数了出来，最后蒸馏成这一个 skill。

> **非官方** · 这是一份表达方法研究，与王自如本人及其团队无关；不使用其声音与肖像，产出的稿子也不应署他的名或冒充本人。

---

## 它解决什么问题

很多人学一个人，学的是金句和口头禅。这有道理，但是非常片面——**真正值钱的不是腔调，而是处理问题的顺序**：

```
审题定义 → 纠偏换尺 → 排除法 → 框架编号 → 比喻回收 → 断言收口
```

直接让 AI "模仿王自如说话"，它只学得到口头禅，学不到结构。这个 skill 强制 AI **先拆解、后写稿**：先交一张《拆解蓝图》，过了质量门才动笔。

## 三种用法

| 模式 | 你给它 | 它给你 |
|---|---|---|
| **A 拆解**（默认） | 一个选题 / 问题 / 产品 / 行业现象 | 一张《拆解蓝图》：4–8 字定义、大众认知靶与"换尺"、排除法靶子（每个都有死因）、2–4 条框架、主比喻与回收点、≤12 字收口句、免责块、待核实清单，末尾附质量门自检表 |
| **B 成稿** | 已确认的蓝图，或"直接写稿" | 两版口播稿：可直接念的**纯净稿** + 带停连 / 重音 / 语调标注的**标注稿**，附分段时长表 |
| **C 体检** | 你写好的旧稿 | 对照质量门的诊断表，先说最致命的 1–2 个问题，再给"原句 → 改写句"对照 |

### 例子：《AI 如何在企业落地》

> 你：用王自如 skill 拆一下《AI 如何在企业落地》
>
> 它给出的定义只有六个字：**给 AI 办入职**。
> 大众盯着的是"AI 够不够聪明"——聪明确实决定上限（先让半步），但换一把尺子：看这位"新员工"第一天上班要补齐几样东西，即**入职成本**。
> 框架是"入职三件套"：**喂资料**（让它读得到）、**开权限**（让它做得了）、**立验收**（让它被验得了）。
> 收口句：**三样没给，再聪明也白搭。**
> 所有需要核实的案例和数据，它会全部标成 `[待核实]` / `[用户补充]`，绝不替你瞎编。

## 质量门（蓝图和成稿共用）

1. 开场 12 秒 ≤40 字，路人 3 秒内答得出"这期讲啥"
2. 定义 ≤8 字，外行能一句话转述
3. "不是 A 而是 B"的 B **可验证**；A 先让半步再推翻
4. 排除法 ≥2 个靶子，每个有**具体死因**，且不是稻草人
5. 主比喻回收 ≥2 次，全片不混用比喻
6. 框架 2–4 条，命名狠，条条平行
7. 收口句 ≤12 字，含数字或绝对词，降调
8. 无一句超 30 字；黑话首次出现带翻译
9. 免责块已按形态 / 商单配装
10. 所有数据、案例有出处或标 `[待核实]`
11. 升华由论证长出，之后接一个真实的破功点


## 怎么说

- "用王自如 skill 拆解一下《XXX》，形态是认知正片，10 分钟"
- "蓝图可以，接着成稿"
- "帮我体检这篇口播稿：（贴稿子）"
- "按王自如的方式写一条 90 秒竖屏口播，讲 XXX"

没给立场时，它会替你选一个**有争议的**立场并说明——没有立场就没有纠偏，没有纠偏就不是这套系统。

## 红线

这套表达法有天然的副作用，skill 里写了对冲规则：

- **不造稻草人**：每个被排除的方案，先公平陈述它最强的版本，再给死因
- **绝对化要有代价意识**：重锤词只用在有机制支撑的地方；预测类断言给出可被打脸的条件
- **不编造**：数据、人名、事件、"我亲测"类经历，一律由你提供或标 `[待核实]`
- **不照搬原句、不冒充**：金句库只用来学句法节奏；稿子是给你自己出镜 / 配音用的，不署王自如的名，也不写成"王自如说"
